# GuideBard

> Turn screen recordings into professional tutorial guides and narrated videos — powered by your own AI API keys.

GuideBard is a self-hostable, single-user application for content creators and SMBs. Record your screen, and GuideBard automatically generates:

- **Text guides** — step-by-step tutorials with annotated screenshots, exportable as PDF
- **Narrated videos** — your recording with AI-generated voiceover, composited into a shareable MP4

Publish directly to **YouTube** and **WordPress.org**, or download and share anywhere.

---

## Quick Start (Self-Hosted)

**Requirements:** Docker + Docker Compose (runs on Linux, Mac, Windows)

```bash
git clone https://github.com/replybotz/GuideBard.git
cd GuideBard
bash scripts/setup.sh
```

Open **http://localhost** in your browser and sign in with the admin credentials you set during setup.

## Features

| Feature | Details |
|---|---|
| Screen Recording | Browser-based — capture full screen, window, or browser tab |
| Auto Screenshots | Pixel-diff detection captures screenshots at meaningful moments |
| AI Guide Generation | Sends screenshots to AI; returns structured step-by-step guide |
| AI Script Generation | AI writes a voiceover narration script from your recording |
| Guide Editor | Rich text editor with drag-to-reorder steps, annotation canvas |
| Video Composition | FFmpeg pipeline: trim + narration audio + caption burn-in → MP4 |
| Voice Synthesis | ElevenLabs or OpenAI TTS; bring your own API key |
| Voice Cloning | Upload a 30-second sample; clone your voice via ElevenLabs |
| YouTube Publishing | Uploads via YouTube Data API v3; set title, tags, privacy |
| WordPress Publishing | Publishes via REST API + Application Passwords; draft or publish |
| PDF Export | WeasyPrint-rendered guide PDF with screenshots |
| Multi-tenancy | Disabled by default (single-tenant); enable via `DEPLOYMENT_MODE=multi_tenant` |

## AI Providers Supported

Add your API key once in **Settings → AI Providers** — all keys are AES-256 encrypted at rest.

| Provider | Use |
|---|---|
| OpenAI | Guide/script generation (vision: GPT-4o) |
| Anthropic | Guide/script generation (vision: Claude) |
| Google Gemini | Guide/script generation (vision: Gemini) |
| xAI Grok | Guide/script generation |
| Perplexity | Guide/script generation |
| OpenRouter | 200+ models via one key |
| ElevenLabs | Voice synthesis + cloning |
| Ollama | Local LLMs — no API key needed |

## Architecture

```
nginx (port 80)
 ├── /          → frontend (Next.js 14, React, TypeScript)
 ├── /api/      → backend (FastAPI, Python)
 └── /ws/       → WebSocket (real-time job progress)

backend services:
 ├── PostgreSQL 16   (with row-level security for multi-tenancy)
 ├── Redis 7         (Celery broker + result backend)
 ├── MinIO           (S3-compatible object storage)
 └── Celery workers  (video processing, AI generation, publishing)
```

## Configuration

All configuration lives in `.env` (auto-generated by `setup.sh`).

| Variable | Description |
|---|---|
| `DEPLOYMENT_MODE` | `single_tenant` (default) or `multi_tenant` |
| `SECRET_KEY` | JWT signing key (auto-generated) |
| `ENCRYPTION_KEY` | AES-256 key for stored API keys (auto-generated) |
| `ADMIN_PASSWORD` | Initial admin password (single-tenant) |
| `MINIO_*` | Object storage credentials |
